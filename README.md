# Vapor 1.0

Vapor — приложение для Windows, которое показывает данные Steam и Discord и помогает управлять игровым временем, карточками, достижениями и заданиями. Работает локально на вашем компьютере. Для доступа к аккаунтам вы входите в них самостоятельно; чужие учётные записи в выпуск не включены.

## Установка и первый запуск

1. Скачайте `Vapor-1.0.0.exe` на странице [Releases](../../releases/latest) и запустите. Устанавливать Node.js не нужно.
2. Войдите в Steam по QR-коду или с логином и подтверждением Steam Guard.
3. Переключитесь на Discord. Для функций, которым нужна активность игры, запустите настольный клиент Discord. Если для заданий требуется токен, подключите **свой** токен во вкладке «Квесты»; никому его не отправляйте.
4. Закрытие окна обычно сворачивает Vapor в трей. Для полного выхода выберите «Завершить работу» в меню значка Vapor в трее.

### Если вход или задания не работают

- **Steam:** вход с VPN иногда не проходит. Попробуйте отключить VPN **на компьютере и на телефоне**, на котором подтверждаете вход, затем повторите попытку.
- **Discord:** из-за региональных ограничений задания могут не отображаться без VPN; даже с VPN они иногда загружаются нестабильно. Проверяйте доступность задания и прогресс в самом Discord. Vapor не гарантирует начисление прогресса или награды.

## Вкладки Steam

| Вкладка | Что делает |
| --- | --- |
| Обзор | Показывает аккаунт, библиотеку и состояние запущенных задач. |
| Фарм часов | Имитирует запуск выбранных игр для учёта игрового времени Steam. |
| Фарм карточек | Находит игры с оставшимися выпадениями карточек и запускает их по очереди. |
| Ачивки | Показывает и изменяет достижения; изменения требуют подтверждения Steam. |
| Экономика | Показывает инвентарь, стоимость предметов и доступные данные кошелька. |
| Аналитика | Статистика библиотеки, времени и профиля; недоступные данные не подменяются примерными. |
| Коллекционер | Подборка бесплатных пакетов. Получение лицензии **не означает** рост значка; смотрите отдельный счётчик Steam. |
| Консоль | Журнал сообщений и ошибок Steam. |
| Настройки Steam | Вход, выход и обновление данных аккаунта. |

## Вкладки Discord

| Вкладка | Что делает |
| --- | --- |
| Квесты | Показывает ваши задания, их серверный прогресс и доступные способы выполнения. Награды забираются отдельно. |
| Универсал | По очереди показывает разные игры в активности Discord. Локальная ротация не подтверждает прогресс значка. |
| Фарм часов | Поддерживает активность выбранных игр в Discord. Начисление времени зависит от Discord. |
| База игр | Поиск игр и поддерживаемых исполняемых файлов. |
| Консоль | Журнал подключений и событий Discord. |
| Настройки Discord | Способ подключения, режим активности и параметры приложения. |

## Данные и безопасность

В установленной версии данные каждого пользователя находятся в его папке `%APPDATA%\Vapor\data` (имя папки может отображаться как `vapor`). Steam-сессия и сохранённый токен Discord относятся только к вашему Windows-профилю; **не передавайте эту папку другим**. Выйти из аккаунта можно в настройках Vapor. Приложение использует локальный сервер на `127.0.0.1`, не открывая его в сеть. Не публикуйте журналы и скриншоты с токенами или личными данными.

## Сборка из исходников

Нужны Windows и Node.js 22.12 или новее:

```powershell
npm ci
npm test
npm run build
npm run app
```

Для создания переносимого выпуска: `npm run release:win`. Результат — в `release/`. При запуске из исходников локальные данные лежат в `data/`; эта папка не должна попадать в Git или архив с приложением. Автоматического обновления и цифровой подписи пока нет: скачивайте новые версии только со страницы Releases.
